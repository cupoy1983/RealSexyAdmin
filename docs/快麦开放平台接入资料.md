## 2. 接入流程

1. 联系快麦 ERP 销售/实施，确认对接场景，提交 API 权限申请
2. 提供：快麦 ERP 公司名称、快麦商家负责人邮箱、对接场景描述
3. 审核 1-3 个工作日；通过后**邮件下发** `APP Key`、`APP Secret`、`accessToken`、`refreshToken` 四件套
4. `appkey` 有效日期与快麦 ERP 账号有效期一致

**硬约束**

- `accessToken` 默认有效期 **30 天**。必须在过期前调用 `open.token.refresh`，否则请求被平台拒绝
- 刷新会话**每小时最多调用一次**
- 刷新成功后 `accessToken` 与 `refreshToken` **值不变**，只是会话时间延长 30 天
- 会话一旦过期，`refreshToken` 同时失效，**只能联系快麦重新开通**（格式：`公司名称-开放平台刷新授权-appKey`）
- API 近 **60 天**无有效调用，开放平台可回收权限
- **报表/智库模块的接口是增值接口**，需单独联系销售报价，不在标准权限内

## 3. 调用协议

### 3.1 公共参数（每个接口都必须传）

| 参数 | 必填 | 说明 |
|---|---|---|
| `method` | 是 | 接口名称，如 `open.token.refresh` |
| `appKey` | 是 | 分配的 AppKey |
| `timestamp` | 是 | GMT+8，例 `2020-09-21 16:58:00`；允许 ±10 分钟误差 |
| `format` | 否 | 默认 `json` |
| `version` | 是 | 协议版本，当前 `1.0` |
| `sign_method` | 否 | `hmac`（默认）/ `md5` / `hmac-sha256` |
| `sign` | 是 | 签名 |
| `session` | 是 | 授权会话，即 `accessToken` |

### 3.2 请求格式

- `Content-Type: multipart/form-data`
- 若用 `application/x-www-form-urlencoded`，Body 里所有参数值也要 URL 编码
- 参数拼装后 URL < 1024 字符可用 GET，否则必须 POST；所有接口都支持 POST
- 接口地址形如 `https://api.kuaimai.com/{method}`
  （例：`https://api.kuaimai.com/open.token.refresh`）

## 4. 已知接口

### 4.1 刷新会话 `open.token.refresh`

请求体：`{ "refreshToken": "..." }`

响应：

```json
{
  "session": {
    "expiresIn": 0,
    "companyId": 0,
    "accessToken": "string",
    "userId": 0,
    "refreshToken": "string"
  }
}
```

注意响应里带 `userId` 和 `companyId` —— 说明快麦侧确实有「用户」维度。

**⚠️ 文档标题写的是「刷新会话(已废弃)」**，但接入指南又明确说这是「必接」接口。
两者矛盾，**新接口是什么需要向快麦确认**（见第 6 节问题 B）。

### 4.2 其他接口

未在公开可访问的文档页里找到完整的接口目录。
**没有找到任何与「员工 / 账号 / 操作员 / 人员」相关的接口。**
店铺、订单、库存等电商域接口存在于商务对接范围内，但需登录后台查看。

## 5. 现有代码与真实协议的差异（重要）

`backend/app/plugin/infra/integration/kuaimai_client.py` 当前实现**与快麦真实协议不符**：

| 项目 | 现有代码 | 快麦真实协议 |
|---|---|---|
| 域名 | `https://openapi.kuaimai.com` | `https://api.kuaimai.com` |
| 取 token | `POST /token`，body 传 app_key/app_secret | 四件套由邮件下发，无「换 token」接口；只有 `open.token.refresh` |
| 鉴权方式 | `Authorization: Bearer <token>` | 公共参数 `session` + `sign` 签名 |
| 签名 | **没有实现** | 必填，`hmac`/`md5`/`hmac-sha256` 三选一 |
| 店铺接口 | `GET /shop/list` | 未核实，路径未知 |
| 配置项 | 依赖 `settings.KUAIMAI_APP_KEY/SECRET` | `setting.py` 中**不存在**这两个字段，`enums.py` 中也没有 `KUAIMAI_ACCESS_TOKEN` |

结论：**该客户端目前是死代码**，调用即报错。要真正接入必须重写（见第 6 节问题 C）。
