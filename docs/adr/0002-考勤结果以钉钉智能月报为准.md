# 考勤结果以钉钉智能月报为准，不再自行计算

考勤结果直接采用钉钉智能考勤报表已经算好的月度汇总，RealSexyAdmin 不根据打卡、排班、请假原始数据重复实现钉钉的考勤规则。因此班次、排班、请假、原始考勤记录四张表及对应功能全部删除；只保留账号绑定能力，并新增月汇总结果表。

## Consequences

- 日粒度的报表数值只在同步过程中用于形成月度结果，不在本系统落库。
- 统计口径以钉钉为准；本系统不自行判定迟到、早退、缺卡、请假。
- 未绑定钉钉账号的 OA 用户不同步、不入库。
- 月报按「OA 用户 + 月份」唯一；重复同步覆盖旧结果，单个用户同步失败时保留旧结果并记录失败。
