# 订单备注上移主订单级，归并时取第一行

系统备注、卖家备注原挂在子订单（订单商品明细）上，但业务上备注是对整个订单的说明，订单列表也按主订单展示备注，因此把两个备注字段移到主订单表，子订单表删除对应列。快麦导出的每一行明细都带备注，同一主订单各行理论上相同；归并时以**第一行**为准写入主订单，不做去重拼接——若真出现行间不一致，以后续行的信息丢失为代价换取单一、确定的取值规则。存量数据在迁移中按同一规则（子订单 id 最小的第一行）回填。

订单类型曾考虑一并上移，最终决定保留在子订单级：拆单场景下同一主订单的各子订单类型可能不同（如一行「平台」一行「补发」），上移会丢失行级语义，且 ADR-0030 的收入判定本就是行级的。
