# 商品成本以系统 SKU 表为唯一事实来源

商品成本价的唯一权威来源是系统内的商品成本主表；快麦 ERP 导出的成本列在导入时**不覆盖**本地成本，只在两者不一致时告警。历史上导商品表和快麦各维护一份成本、经常对不上，团队决定后续只维护一处；选系统表而非快麦为准，是因为成本要在系统内被修正、补录、追溯，不能每次导入都被 ERP 冲掉。

> 2026-10-24 补充：本表的主键语义变了——规格商家编码改为选填（NULL=无规格）、主商家编码必填，两码相同一律归一化。因此「唯一事实来源」的查找路径从「只按规格编码单键命中」改成两段式：规格编码有值走（主+规格）精确命中，无规格走主编码兜底且不越有权属。口径细则见 ADR-0023 的修订块。

> 2026-10-28 补充：**本条ADR有了第一条例外**——「分销订单」（标签含 `已生成采购单`、由 1688 商家代发）的商品成本**不从本表取**，取 Excel 的 `系统实发成本` 原值，且不跑本表与原值的差异告警、不判 `cost_missing`。例外成立的理由是这批货根本不经过我们的仓库，本表里没有它的成本口径；判据、代价与配套口径见 **ADR-0036**。除这一类之外，本条 ADR 一字未改。
