# 考勤同步走系统节点任务，并保留代码块执行开关

业务要求能通过 RealSexyAdmin 的系统定时任务页面配置和手动执行钉钉月报同步。当前框架的定时任务节点就是「保存代码块 + exec 执行」，节点任务没有其他执行入口；`SCHEDULER_ALLOW_CODE_EXEC=False` 会让节点任务无法注册和执行。因此这里接受 `SCHEDULER_ALLOW_CODE_EXEC=True`，同时把真实逻辑预先写进 Service，节点代码块只调用 Service，不再保留业务模块里硬编码的 APScheduler 注册。

## Consequences

- 定时计划（每月 7 号同步上月）和执行时间由系统定时任务节点配置，不再保留 `DINGTALK_ATTENDANCE_*` 调度配置。
- 业务模块不再自己注册 cron 任务，避免与节点任务重复执行。
- 风险点：拥有节点任务管理权限的人可以提交代码块，等同于服务器执行权限，因此该能力只应授予可信管理员。
