# 不做数据隔离，全团队共享

利润数据**不使用**框架 ModelMixin 的 `data_scope` 隔离能力，全团队可见所有店铺数据；归属关系仅通过 Store 上的负责人(tag)字段表达。团队规模小、需要互相补位看全盘，隔离反而妨碍协作；负责人字段用于分摊归集和提醒，不用于权限过滤。

> **运维前提（2026-10-27 补，AB7）**：「不使用」不等于「框架不会生效」。框架在 `app/core/base_crud.py` 里按当前用户角色的**数据范围**注入过滤条件（`Permission._permission_condition()`，值 1=仅本人、2=本部门及以下、3=全部），电商的业务代码绕不开它。**相关角色的数据范围必须保持「全部」**，否则电商页面会整片空表——而且空得毫无提示，看起来像「这个月没数据」。这一条不改代码（改就是动框架、违背「只做业务代码」的硬约定），只把它当作部署/建号时的检查项。
>
> 入口在**系统管理 → 角色管理 → 该角色行操作「分配权限」抽屉**里的「数据范围」下拉（不是「编辑角色」弹窗，那里没有这个字段）；角色列表上的「数据权限」列显示的就是同一个值。本仓库的 dev 库已由用户改好。
