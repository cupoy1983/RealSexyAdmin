# 刷单订单以订单与销量权重审批逐笔核对后排除收入

刷单订单不直接依据订单备注或审批汇总金额自动排除。订单备注中的刷单标记必须与钉钉「销量权重」审批明细逐笔对应，按订单号和金额精确到分匹配；一条审批可以包含多个订单。订单缺少审批、审批缺少订单、金额不一致或订单重复核对，均属于重大错误，阻止整个结算月份结算，并通过企业微信群通知管理员。

核对成功后，刷单订单的销售额不计入实际销售额，刷单订单数单独展示且不计入正常订单总数；商品成本仍按系统 SKU 成本表计算，实际产生的运费仍计入成本。刷单整单退款时，若存在正向刷单审批，必须存在金额精确匹配的负向「销量权重」审批；若不存在正向审批，则不要求负向审批。部分退款属于重大错误。

选择逐笔核对而不是只核对汇总金额，是为了避免一笔审批被错误分配到多个订单，并保留每笔刷单及刷单退款的可追溯性。
