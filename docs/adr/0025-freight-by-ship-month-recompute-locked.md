# 运费按子订单发货月归属，迟到账单重算已锁定月

运单号和发货时间挂在子订单（订单商品明细）级，一个主订单可以拆成多个包裹、有多个运单号，因此运费成本记在子订单上、按**子订单发货时间所属月份**归属（不是账单月）。选重算而非顺延，是因为利润要如实反映发货当月的成本，顺延会让两个月都失真、且对账更复杂。

当迟到账单命中一个已结算锁定的月份时，标记待处理事项并记日志、发送企微通知；管理员确认后必须经过**解锁→重算→重锁**流程，不得绕过锁定状态直接改写利润。

> **机制已由 [ADR-0034](./0034-freight-written-onto-suborder-no-match-table.md) 修订，本 ADR 的归属月原则不变。** 原先「账单月匹配不到就回溯上月订单（≤1 个月）、已匹配过的运单号不再二次匹配」这两条都随独立匹配表的删除而废弃：改为**全局按运单号在 `ERP发货` 子订单中查找**，命中几条摊几条。运单号本身全局唯一，出账月只决定账单文件何时导入，不参与「这笔运费属于哪个月」的判断，所以不需要用月份限制查找范围。迟到账单依然按子订单发货月归属，走解锁→重算→重锁。
