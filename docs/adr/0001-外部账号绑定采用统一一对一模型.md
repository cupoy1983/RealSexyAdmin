# 外部账号绑定采用统一一对一模型

业务要求是「一个 OA 用户对应一个钉钉用户、一个快麦用户、一个企业微信用户」，且后两者要先预留。因此不再按外部系统各建一张映射表，而是采用统一的外部账号绑定模型：绑定记录带外部系统类型，唯一约束落在「系统类型 + OA 用户」与「系统类型 + 外部账号」上。本期只实现钉钉，快麦、企业微信后续只需增加系统类型即可，不需要再改表结构。

## Consequences

- 钉钉一侧仍然是强一对一：一个 OA 用户只能绑定一个钉钉成员，一个钉钉成员也只能绑定一个 OA 用户。
- 手机号在每个外部系统内部唯一；同一个员工可以在不同外部系统中使用同一个手机号，因此唯一约束不能跨系统建立。
- 绑定成功后锁定，页面不提供改绑和解绑入口；绑错只能由数据库或后续专门管理功能处理。
