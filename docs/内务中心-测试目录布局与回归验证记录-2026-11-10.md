合并后要核对的清单：

1. 两个 clone 的 `origin` 实测都是 `https://github.com/cupoy1983/RealSexyAdmin`、都在 `master`；2026-11-10 实测 Admin 的 HEAD 是 RealSexy-OA HEAD 的祖先，本仓领先 8 个提交。但 `docs/agents/shared-rules.md`、`scripts/adr.mjs`、`docs/adr/domains.json` 在 Admin 里是**未跟踪文件**，从未进过 Git 历史，所以本仓看不到。合并靠 git 快进／merge，不是复制文件；合并后登记表只会有一份，届时不要在两个 clone 各建一份。
