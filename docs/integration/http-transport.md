# 第三方接口 HTTP 传输

共享入口为 `backend/app/plugin/infra/integration/http.py` 的 `request_json`。

## 环境代理隔离（2026-11-27）

已确认共享请求使用 `httpx.AsyncClient(..., trust_env=False)`，不继承启动终端的代理和证书环境变量，避免失效的临时代理影响快麦、钉钉等服务。当前通过服务器网络直连；若以后确需代理，应另行明确配置，不能依赖启动终端的隐式环境。

传输层保留原始 HTTP 异常类型，第三方客户端负责业务错误翻译及是否重试。商品中心 OA 的快麦客户端已包装连接异常，合并时保留该处理及仅只读请求重试的规则，不用旧版快麦客户端覆盖它。

验收：给进程注入不可连接的代理，通过真实本地 HTTP 服务调用 `request_json`，仍须成功获得 JSON。该测试不使用真实平台凭据。

此修改在 selection worktree 完成；不会自动更新另一个检出或已运行的商品中心后端。同步修改后需重启对应后端。
