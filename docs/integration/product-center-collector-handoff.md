# 给商品中心 agent：Collector 对接修复清单

只修改商品中心业务；Collector 窗口授权隔离由采集侧处理，双方完成后联合验收。

Collector 的标签页窗口标识由其入口和登录页面内部维护；商品中心继续调用现有 access／operation／entry 接口，不需要自己传 `X-Collector-Window` 或直接控制 noVNC。请不要另造窗口授权协议。

本次发布包含 `current_product` 接口和 SDK，商品中心须同步该版本；线上是否生效应实测确认。上线时双方需同步版本；`capabilities.current_product_lookup` 为 true 才表示服务提供当前商品查询，未升级时明确提示版本不满足，不要因此偷偷新建采集。

1. **商品结果与登录会话解耦（业务方新确认）。** 结果按平台＋规范 URL 共享，不含会话名，也不按账号价格差异分组。在业务服务权限范围内优先调用 `current_product(platform=..., url=...)` 读取已有成功结果；没有结果或明确更新时才走登录准入及新采集。切换账号允许保留并展示相同商品结果，来源仍展示实际采集任务账号。废弃旧登录操作／会话检查及晚到响应，不能拿旧账号的登录状态覆盖新账号；不要仅在前端伪造一个新账号的任务。浏览器跨系统用户复用时清理不属于该服务权限范围的缓存。
2. **普通读取复用最新结果，主动重采必须实际执行。** 打开商品、查看结果、普通「开始采集」优先调用 current；没有结果且已有任务执行中时显示其进度。读取已覆盖旧任务时，直接用 current 或有界、防循环地跟随 `superseded_by`，核对调用方、平台、规范 URL，不要求会话名相同，不额外采集。**点击「重新采集／更新数据」必须走新一轮 submit，即使已有成功结果也不能被缓存短路。** 每轮使用新的幂等键，同一轮连点、请求重试或响应不确定时重用该键和任务 ID；执行中按钮置忙、继续显示进度。不能所有重采永远用第一次的固定键，也不能每次网络重试都生成新键。更新成功替换结果；失败保留旧成功结果并展示失败原因，更新期间可同时显示旧结果与进度。只有明确的 `product_not_found` 才按无结果处理，版本不足、网络错误、鉴权失败与 410 分开处理。无需新增 Collector force 参数。
3. **新任务与幂等重放任务都刷新异常会话。** 这里的重复点击指同链接的「开始采集」或同一轮执行中的重试，可能返回已有任务。无论返回新任务还是已有任务，`needs_login`／`needs_verification` 后都读取一次该任务实际会话的 `session_status`，不要在 `replayed` 分支提前跳过，不调用 `force=true`，不伪造正常或掉线。当前已切到其他会话时，不把旧任务异常显示成新账号失效。处理登录／验证后，用户明确再试时创建新一轮，不能永远返回已终止的失败任务。
4. **人工保存后自动刷新。** 原弹框在返回焦点或收到登录完成信号后只读会话状态；避免重复监听、无限轮询及旧请求覆盖新会话。
5. **准备生产地址。** API 与人工入口共用 HTTPS origin 可以沿用 SDK 默认值；若内部 API 与外部入口不同，增加后台可信 `browser_origin` 配置并传给 `CollectorClient.login_entry`，不要接收前端任意 origin。服务器不能沿用开发笔记本的 localhost 地址。
6. **合入 HTTP 代理隔离修复。** master 提交 `3fd66fe0`；共享请求设置 `trust_env=False`，同步后重启商品中心后台。保留现有快麦业务异常包装与只读连接重试。

不要擅自改为个人账号独占；中心内共享账号、不做用户映射是现行选择。商品结果不按会话分组，登录状态与人工窗口仍严格按会话和窗口隔离。详细合同见 `product-result-session-decoupling.md`。

## 对方完成后提供

最终提交号、改动文件、测试结果、生产 API／入口配置方式（不含密钥）。

## 联合验收

1. 打开商品或普通开始：有成功结果直接展示，不新增任务；切换登录会话也复用同一商品结果，实际来源不改，未登录仍可查看已有结果。
2. 已有成功结果时点击「重新采集／更新数据」：确实产生新一轮采集，不能只读缓存；同轮连点与网络重试仍只有一个任务。
3. 更新成功后展示新结果；更新失败仍能查看旧成功结果并看到失败原因。
4. 打开被覆盖的旧任务：展示已有最新结果，不创建额外任务；跨会话替代同样成立。
5. 新任务与重放任务出现登录／验证异常时，均只读刷新实际会话状态，不强制打开浏览器；处理后明确再试可执行新一轮。
6. 人工保存后原弹框自动刷新；切换账号不串登录状态；生产 HTTPS 入口和 WebSocket 可用；旧窗口授权不能进入新窗口。
