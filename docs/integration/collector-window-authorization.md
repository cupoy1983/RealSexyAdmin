# Collector 人工窗口授权修复

## 已确认方案（2026-11-27）

修复目标：人工入口授权只适用于当前窗口，不能越过取消、保存、过期、关闭或下一次登录。成功保存的平台授权仍按原规则供采集复用；此处只收紧人工远程窗口的访问授权。

1. 每次开启、关闭人工窗口轮换入口签名密钥，并撤销该代的 Cookie 与尚未兑换票据。状态含平台、会话名和窗口截止时间；同一仍活动窗口重新领取入口不重启浏览器、不轮换。
2. 新 Cookie 的截止时间不得超过当前窗口截止时间。没有活动窗口时，SSH 签发入口仅允许打开管理页；开始登录后，仅将发起本次操作且已通过授权的管理 Cookie 移交到新窗口。其他旧 Cookie 全部失效。窗口结束后须重新申请入口。
3. 管理命令在取得浏览器管理锁后再次检查 Cookie，避免排队请求跨越窗口边界。共享服务 API 继续使用服务鉴权，不能用浏览器 Cookie 替代。
4. noVNC WebSocket 改走登录进程的受控中继，websockify 保持容器内回环。握手与后续传输均校验窗口授权；窗口结束同步关闭已登记通道，空闲连接也会断开。仅改 Cookie 有效期或 nginx 初始握手鉴权不足以解决已连接通道。
5. nginx 的精确 WebSocket 路由必须转到新中继；通用 viewer 路由不得留下绕过该中继的 WebSocket 升级入口。代码与 nginx 必须一起发布。更新前结束正在操作的窗口，旧入口因升级失效，平台保存状态、浏览器 profile、中文配置与业务结果保留。
6. 同一浏览器的多个标签页共享 Cookie，因此还需标签页窗口标识：兑换入口后在该标签页 sessionStorage 保存 window_id；状态与命令带 X-Collector-Window，WebSocket URL 带 window 参数。旧页不能因另一个标签页更新 Cookie 而接入下一窗口。管理页开始登录时只允许从其管理代次移交到本次新窗口，后续看到不同窗口标识应终止旧页。
7. 现有中文辅助剪贴板也属于窗口操作：网关的 `/text/` 路由经登录进程校验标签页窗口标识，并在管理锁内转发给原回环剪贴板服务。这样旧页不能通过中文辅助通道影响新窗口；中文输入工具和 UTF-8 处理保持原实现。

## 验收

- 旧窗口结束后，未兑换票据、Cookie 和已经建立的 WebSocket 均失效；下一窗口不接受上一窗口授权。
- 窗口有效期到达即停止传输，不等待客户端发新请求。
- 当前窗口重复领取入口可用；SSH 管理页开始登录后当前操作人仍可继续，其他管理页失效。
- 原生 Chrome 和 Playwright 登录模式均覆盖开始、保存、取消、过期及启动失败清理。
- 不改变十二小时平台会话复用、人工登录方式或采集结果生命周期。

本次先在 worktree 实现与隔离测试。生产发布需同时核对登录镜像和 nginx 路由；未发布不能称线上已修复。商品中心的问题另行交接，修改完成后再做联合验收。

## 实现结果

窗口结束前同步撤销入口密钥、Cookie 与远程通道；真实 HTTP 和 TCP 测试覆盖旧授权、旧页持新 Cookie、空闲连接、两种浏览器生命周期。入口签发与命令执行在管理锁内复核；原生进程退出期间保持 closing 状态，桥接核对原窗口对象，不能将排队后的其他窗口入口发回旧请求。

登录页在开始登录期间暂停后台状态刷新，并丢弃晚到的旧代次响应；窗口结束停止请求并显示结束状态。镜像升级识别现有 nginx 和页面，只修改需要的内容，未知布局失败退出。

本次发布包含此修复；商品中心代码由所属 agent 对接。联合验收需等待对方业务修改完成，并在实际网关发布后验证。离线测试通过不能代替真实浏览器和生产路由验收。

本轮相关回归最终为 95 项通过；旧中文页面升级后的辅助请求带窗口标识，JavaScript 语法检查通过。ADR 引用与敏感信息检查通过。本轮不新增 ADR，也不调整业务账号共享规则。
