# 全局 (Global)

不属于电商也不属于内务的共同语境：两边共用同一套后端进程、同一份定时任务清单时才会出现的概念。本术语表只定义领域语言，不含实现细节。

## 语言

### 定时任务与多进程

**持锁进程**:
同一份定时任务清单同时被多个后端进程挂着时，真正握着执行权、到点把任务跑起来的那一个。同一时刻只有一个，谁先抢到谁当。
_Avoid_: 主进程（没有主从分工，也不固定由哪个进程担任）

**候选进程**:
没握着执行权、隔几秒试一次准备接班的其余进程。任务清单在它那里照常可见可改，只是到点不由它执行。
_Avoid_: 从进程、备用进程（它不担"待命之外"的任何分工）

**静默假活**:
一个进程失去执行权又接回班之后，任务照常挂在清单里、到点却一次也不执行，而且连一条失败记录都不留的状态。
界面上任务列表是满的、没有任何一处报错，实际上那一档时间什么都没发生。
_Avoid_: 任务丢失（任务没丢，是不执行）、假死（进程活着，问题不在进程上）
