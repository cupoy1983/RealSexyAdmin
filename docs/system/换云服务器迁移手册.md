# 换云服务器（腾讯云 → 阿里云）

只换外网那台云机，域名仍是 `admin.realsxy.cn`。库、后端、上传文件都在家里 Armbian，不动。
IP／frp token／私钥不进仓库，一律现查。

## 阶段一：新机准备（不停机）

1. **买实例**。阿里云，包年包月且剩余时长够备案接入（这次要求**未实测**，下单前在备案流程核对）。
2. **装 1Panel，在里面装 OpenResty 和 frps**。只要 frps 起得来。
3. **抄旧云机现值**（输出存你本机运维记录，别贴进仓库）：

   ```
   docker ps
   ls -1 /srv/RealSexyAdmin
   ls -1 ~/.acme.sh
   docker inspect --format "{{json .Mounts}}" openresty
   docker inspect --format "{{json .Mounts}}" frps
   docker exec frps cat /etc/frp/frps.toml
   crontab -l
   ```

   `.Mounts` 里的 `Source` 就是这台机器 1Panel 存配置的目录，各机不同，别写死 `/opt/1panel`。别加 `2>/dev/null`。
4. **带四样到新机**：
   - 前端页面：本机 `pnpm run build` → `scp -r dist/. root@<新云机>:/srv/RealSexyAdmin/`（别拷旧 `dist/`）。
   - OpenResty 站点配置：不在 Git 里，只能从旧机 dump 过去改。
   - 证书那对文件（`~/.acme.sh/<域名>_ecc/`）：只认域名，照用。
   - frps 配置：token 沿用旧机的，这样家里 frpc 不动。
5. **新机装 acme.sh 自动续期**，`crontab -l` 里要看到那条。
6. **安全组只放 80、443、7000 和 SSH**（SSH 来源限网段）。`7500` 不放。
7. **新机自测**：

   ```
   curl -s -o /dev/null -w "%{http_code}\n" --resolve admin.realsxy.cn:443:127.0.0.1 https://admin.realsxy.cn/
   ```

   出 `200` 才算成。
8. **阿里云提交「新增接入」备案**，主体资料不变。然后等审批，旧机照常跑。

家里 frpc 的 `serverAddr` 已经是域名（2026-11-19 验过），所以这一趟家里零操作。

## 阶段二：切解析（备案通过之后）

1. 前一天把 `realsxy.cn` 的 A 记录 TTL 调到 600 秒或更低。改的地方看 `dig +short NS realsxy.cn`。
2. A 记录改成新机 IP。
3. 等几分钟，跑验收。
4. 旧机不停服务、不删文件、不退订。

## 验收

```
curl -s -o /dev/null -w "首页=%{http_code}\n" https://admin.realsxy.cn/
curl -s -o /dev/null -w "跳转=%{http_code} 目标=%{redirect_url}\n" http://admin.realsxy.cn/
curl -s -o /dev/null -w "参数接口=%{http_code}\n" https://admin.realsxy.cn/api/v1/system/param/info
curl --http1.1 -s -o /dev/null -w "WSS握手=%{http_code}\n" https://admin.realsxy.cn/api/v1/ai/chat/ws
echo | openssl s_client -connect admin.realsxy.cn:443 -servername admin.realsxy.cn | openssl x509 -noout -enddate
```

首页 200；跳转 301／302 到 https；参数接口 200，且 `favicon`／`logo_url`／备案号原样还在；
WSS **403**（必须带 `--http1.1`，不带必得假 404，别去改配置）；证书剩 30 天以上。
再浏览器真登一次，看到点的定时任务有一格执行记录——同时只能跑一套后端，两套会静默不执行。

## 回滚

A 记录改回旧机 IP，恢复时间等于 TTL。前提：旧机服务没停、旧 frps 还在听 7000。

## 旧机退订

新机跑过一次凌晨定时任务 + 一次月初考勤／账单动作再退（`ADR-0012`、`ADR-0008` 那些时点动作都靠持锁进程在跑）；退订前留快照。

## 三条只能记在这里的事

- `backend/env/.env.prod` 不在 Git、也没有模板，重装 Armbian 才发现没了就只能逐键重建 → 现在就单独备份到仓库外。
- 旧机的 `dist/` 比 `frontend/web/public/` 落后，缺三份 logo 的 svg，线上 404（2026-11-18 实测）。
